The following code is a partially functional (as of July 2025) port of mod_offhangar v1.0.0.0 by IzeBerg created for World of Tanks 0.9.22.0.1 to World of Tanks 0.8.2, which targets the same task — allow the user to explore hangar UI in offline mode, inspect vehicles, etc.

<img width="1919" height="1199" alt="image" src="https://github.com/user-attachments/assets/d96a6d9d-ce8e-4f8e-81b8-a6e288430ce9" />

Requires [Python 2.6.6 x32](https://www.python.org/downloads/release/python-266/) to be compiled and used in the game or extract two files from [this archive](https://k2mg.net/res/storage/python26.7z) into your PjOrion folder and change your Python library to python26.dll via Terminal -> Settings -> Basic setup.
