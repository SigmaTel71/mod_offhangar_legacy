The following code is a partially functional (as of July 2025) port of mod_offhangar v1.0.0.0 by IzeBerg created for World of Tanks 0.9.22.0.1 to World of Tanks 0.8.2, which targets the same task — allow the user to explore hangar UI in offline mode, inspect vehicles, etc.
