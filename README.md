The following code is a partially functional (as of June 2024) port of mod_offhangar v1.0.0.0 by IzeBerg created for World of Tanks 0.9.22.0.1 to World of Tanks 0.8.2, which targets the same task — allow the user to explore hangar UI in offline mode, inspect vehicles, etc.

![shot_015](https://github.com/SigmaTel71/mod_offhangar_legacy/assets/17989678/dd93774e-502b-4291-9ccc-3ca5a2707d99)

Requires [Python 2.6.6 x32](https://www.python.org/downloads/release/python-266/) to be compiled and used in the game or extract two files from [this archive](https://k2mg.net/res/storage/python26.7z) into your PjOrion folder and change your Python library to python26.dll via Terminal -> Settings -> Basic setup.

![image](https://github.com/SigmaTel71/mod_offhangar_legacy/assets/17989678/a012b37e-4d07-4d4b-b2fd-81aac811cde5)

You can discuss the mod, file a bug report outside GitHub or ask another related question on [EI Forums](https://forum.k2mg.net/?showtopic=1974). **This is the only alternative way of communication we officially provide.**
